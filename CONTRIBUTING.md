# Contributing

Thanks for helping make local home automation safer and easier to reproduce.

- Open an issue describing the exact operator model, control board part number, and behavior before proposing different wiring.
- If suggesting a wiring correction, cite the *specific* operator's manual and how you independently verified it. Never infer terminal polarity from color or an unrelated model.
- Do not post gate access credentials, Home Assistant URLs, street addresses, key codes, serial numbers, or identifying exterior/property photos.
- Preserve all entrapment devices, local stop functions, and other manufacturer-required protection. No bypasses or hacks to override safeties are accepted.
- Label untested changes **experimental**, even when they compile.
- Prefer modest, reviewable pull requests; include the YAML validation command and test evidence when relevant.
